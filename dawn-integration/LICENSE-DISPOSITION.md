# AI Content Studio licence disposition

## Verified repository state

No repository licence file or licence declaration was found during the Wave 1 review.

## Consequence

In the absence of an explicit licence, upstream implementation code, UI assets, text, templates and other copyrighted expression must not be copied into a commercial DAWN product.

The current DAWN workstream is therefore limited to:

- independent analysis of functional ideas;
- original DAWN schemas and interface contracts;
- original test fixtures and acceptance logic;
- mappings to services DAWN already operates;
- independently implemented, provider-neutral workflows.

## Merge gate

The original files under `dawn-integration/` may become technically merge-ready when their tests pass. No upstream implementation may be incorporated unless a suitable licence or written permission is later verified.

## Required evidence

Before any broader adoption, record:

1. the exact upstream commit reviewed;
2. whether a licence has subsequently been added;
3. a code-origin review showing DAWN implementation was independently written;
4. a duplication assessment against ComfyUI, Google Flow, FFmpeg, Postiz and existing DAWN services;
5. confirmation that no direct publishing or production credentials are enabled.
